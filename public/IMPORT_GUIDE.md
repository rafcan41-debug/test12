# 📥 প্রশ্ন ইমপোর্ট গাইড (বিগত বছরের প্রশ্ন যোগ করা)

এই গাইড দিয়ে তুমি তোমার বই/গাইড থেকে **বিগত বছরের আসল প্রশ্ন** নিজে টাইপ করে
প্রশ্ন ব্যাংকে যোগ করতে পারবে। একবারে সর্বোচ্চ **৫০০টি** প্রশ্ন ইমপোর্ট করা যায়।

## ধাপ ১: টেমপ্লেট ডাউনলোড করো

অ্যাডমিন প্যানেল → **📥 ইমপোর্ট** ট্যাব → **template-questions.json** ডাউনলোড করো।
অথবা সরাসরি: `https://তোমার-সাইট/template-questions.json`

## ধাপ ২: প্রশ্ন সাজাও

টেমপ্লেটের মতো করে JSON সাজাও। প্রতিটি প্রশ্নে এই ফিল্ডগুলো থাকে:

| ফিল্ড | বাধ্যতামূলক? | উদাহরণ |
|---|---|---|
| `question_text` | ✅ হ্যাঁ | `"২০২৪ সালে ঢাকা বোর্ডে আসা প্রশ্নটি এখানে লিখো"` |
| `option_a` … `option_d` | ✅ হ্যাঁ | `"ঢাকা"`, `"রাজশাহী"` … |
| `correct_option` | ✅ হ্যাঁ | `"a"`, `"b"`, `"c"` বা `"d"` |
| `subject_id` | ✅ হ্যাঁ | `9` (বিষয়ের ID — নিচে দেখো) |
| `explanation` | ঐচ্ছিক | `"বাংলায় ব্যাখ্যা"` |
| `difficulty` | ঐচ্ছিক | `"easy"`, `"medium"`, `"hard"` |
| `marks` | ঐচ্ছিক | `1` |
| `year` | ঐচ্ছিক | `2024` — কোন সালের প্রশ্ন |
| `source` | ঐচ্ছিক | `"SSC Dhaka Board"`, `"Medical Admission"`, `"BCS Preliminary"` |
| `prev_year` | ঐচ্ছিক | `true` — বিগত বছরের প্রশ্ন হলে |
| `chapter_id`, `topic_id` | ঐচ্ছিক | অধ্যায়/টপিকের ID (না জানলে `null`) |
| `tags` | ঐচ্ছিক | `"সন্ধি, ব্যাকরণ"` |

`year` বা `source` দিলে প্রশ্নটি স্বয়ংক্রিয়ভাবে **বিগত বছরের প্রশ্ন** হিসেবে চিহ্নিত হয়,
এবং প্র্যাকটিস পেজ ও পরীক্ষার ফিল্টারে বছর/উৎস অনুযায়ী খুঁজে পাওয়া যায়।

### বিষয়ের ID কীভাবে জানবে?

অ্যাডমিন প্যানেল → **❓ প্রশ্ন ব্যাংক** → "নতুন প্রশ্ন" ফর্মে বিষয়ের ড্রপডাউন দেখো,
অথবা API: `GET /api/catalog` (লগইন করে ব্রাউজারে খুললেই JSON দেখা যাবে)।

## ধাপ ৩: ইমপোর্ট করো

1. অ্যাডমিন প্যানেল → **📥 ইমপোর্ট**
2. পুরো JSON (`{"questions": [...]}`) কপি করে বক্সে পেস্ট করো
3. **ইমপোর্ট করো** চাপো
4. কতগুলো যোগ হলো + কোনগুলোতে ভুল আছে — রিপোর্ট দেখাবে

## ধাপ ৪: যাচাই করে প্রকাশ করো

ইমপোর্ট করা সব প্রশ্ন **ড্রাফট** হিসেবে আসে — ছাত্ররা দেখতে পায় না।
**❓ প্রশ্ন ব্যাংক** ট্যাবে গিয়ে প্রতিটি প্রশ্ন পড়ে যাচাই করো, তারপর **প্রকাশ** চাপো।

## ⚠️ গুরুত্বপূর্ণ নিয়ম

- **নিজে টাইপ করো**: বই/গাইড দেখে নিজের হাতে টাইপ করো। অন্য ওয়েবসাইটের প্রশ্নব্যাংক
  থেকে কপি-পেস্ট কোরো না — এতে কপিরাইট সমস্যা হতে পারে।
- **উত্তর দুবার মিলিয়ে দেখো**: ভুল উত্তর প্রকাশ হলে ছাত্ররা ভুল শিখবে।
- **ব্যাখ্যা বাংলায় লিখো**: ছাত্রদের বোঝার জন্য সহজ ভাষায় ব্যাখ্যা দাও।
- **উৎস সঠিক লিখো**: যেমন `"SSC Dhaka Board 2024"` না লিখে `year: 2024`,
  `source: "SSC Dhaka Board"` — এভাবে ফিল্টার ঠিকমতো কাজ করবে।
