# Porikkha — Website Update & Question Bank Requirements (Shoel, 2026-10-16)

## 1. Custom Exam System
- User chooses total number of questions for the exam.
- User selects MULTIPLE topics/chapters; questions are drawn from all selected and SHUFFLED into one complete test.
- After submit, result page shows ALL questions by default, with filter buttons:
  1. Correct Answer (সঠিক)
  2. Wrong Answer (ভুল)
  3. Skipped Question (উত্তর দেওয়া হয়নি)
- Selecting a filter shows only that type.

## 2. Quick Practice — Class 11-12 Group option (CURRENTLY MISSING)
- After selecting Class 11-12, user must pick a Group: Science / Humanities / Business Studies.
- Then show that group's Subjects → Papers → Chapters.
- User picks subject/paper/chapter or multiple topics → Quick Practice.

## 3. Class 11-12 Question Bank (per subject per paper: 3000 questions)
RULES: Follow board textbooks + syllabus for alignment, but write ORIGINAL
questions (never copy textbook text verbatim — copyright). No duplicate
questions to pad counts. Each question stores: Class, Group, Subject, Paper,
Chapter/Topic, Question, Options, Correct Answer, Explanation (where useful).

### A. Business Studies (mandatory — 18,000)
| Subject | Paper 1 | Paper 2 | Total |
| হিসাববিজ্ঞান | 3000 | 3000 | 6000 |
| ব্যবসায় সংগঠন ও ব্যবস্থাপনা | 3000 | 3000 | 6000 |
| ফিন্যান্স, ব্যাংকিং ও বিমা | 3000 | 3000 | 6000 |
Optional (each 6000: 3000+3000, separate bank): অর্থনীতি, উৎপাদন ব্যবস্থাপনা ও বিপণন.

### B. Science (same 3000/paper rule)
Subjects: পদার্থবিজ্ঞান, রসায়ন, উচ্চতর গণিত, জীববিজ্ঞান (each 2 papers × 3000).
Optional subjects same rule.

### C. Humanities (same 3000/paper rule)
Board-approved subjects, each 2 papers × 3000. Optional subjects same rule.

### 4. Compulsory (all groups): বাংলা, English, ICT
- বাংলা 1st paper categories: গদ্য, কবিতা, লেখক ও কবি পরিচিতি, মূলভাব, চরিত্র বিশ্লেষণ, ঘটনা/উদ্ধৃতি, সহপাঠ (উপন্যাস/নাটক separate bank).
- বাংলা 2nd paper: ব্যাকরণ, সন্ধি/সমাস/কারক, উপসর্গ/প্রত্যয়, বানান, বাগধারা, নির্মিতি.
- English 1st: lessons, comprehension, vocabulary, information transfer, summary.
- English 2nd: tense, right form of verbs, articles, prepositions, voice, narration, transformation, connectors, etc.
- ICT: chapter-wise MCQ (সংখ্যা পদ্ধতি, প্রোগ্রামিং, ডেটাবেজ, নেটওয়ার্কিং...).
- Counts: 3000 per paper (Bangla 6000, English 6000, ICT 3000).

## 5. Structure
Class → Group → Subject → Paper → Chapter → Topic → Questions.
One bank feeds Quick Practice, Chapter-wise, Topic-wise, Custom Test, Full Exam.

## 6. Goal
Full platform: class+group → subject+paper → chapter/topic → practice/custom test →
count selection → filtered results. Accurate, textbook-aligned, syllabus-based,
diverse, no repeats.
